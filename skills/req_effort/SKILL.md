# 需求评估技能 (req_effort)

## 使用时机
当用户需要：
1. 评估客户需求并进行工作量估算
2. 将需求拆分为具体任务模块
3. 识别需要客户澄清的问题
4. 进行多轮需求评估和调整

## 核心概念

### 目录结构
```
./
├── .req_effort/                              # 中间记录文件目录
│   ├── {项目名称}_assessment_history.json    # 评估历史 JSON
│   └── {项目名称}_round_{N}.md               # 第 N 轮详细评估报告
└── req_effort_{项目名称}.md                  # 最终输出给用户的简化报告
```

### 历史记录持久化
- 中间记录文件（包括 JSON 历史和各轮次详细 md 报告）保存至 `.req_effort` 目录
- 历史记录文件命名：`{项目名称}_assessment_history.json`，数据结构参考：`example_history.json`
- 轮次详细报告命名：`{项目名称}_round_{N}.md`，保存至 `.req_effort` 目录
- 最终输出给用户的简化报告命名：`req_effort_{项目名称}.md`，保存在当前目录

### 功能点深度评估
复杂功能点可使用 `function_point_template.md` 进行详细评估

## 核心功能

### 1. 需求理解与拆分
- 分析客户需求文档或描述
- 识别核心功能和次要功能
- 将需求拆分为具体的任务模块
- 为每个功能点分配唯一标识符

### 2. 功能点细节评估
- 为每个拆分的功能点进行详细工时评估
- 记录每个功能点的工作量分配
- 支持功能点级别的调整和变更追踪

### 3. 多角色工作量评估
- **前端开发**：评估界面实现、交互逻辑等工作量
- **UI设计**：评估界面设计、视觉效果等工作量
- **AI工程师**：评估AI模型开发、集成等工作量
- **测试工程师**：评估测试用例编写、执行、回归测试等工作量
- **PM项目经理**：评估项目管理、协调等工作量
- **部署运维**：评估环境配置、部署、监控等工作量

### 4. 需求澄清识别
- 识别需求中的模糊描述
- 发现需求中的矛盾点
- 列出需要客户明确的问题

### 5. 多轮评估支持
- 支持基于反馈的评估调整
- 清晰记录评估变化
- 跟踪未解决的澄清问题

## 工作流程

### 初始评估流程（第1轮）
1. 向用户确认项目名称
2. 检查是否存在该项目的历史记录文件
3. 获取客户需求文档或描述
4. 分析需求内容，确认理解正确性
5. 将需求拆分为具体功能模块
6. 对复杂功能点使用 `function_point_template.md` 进行详细评估（可选）
7. 评估各角色工作量（人天）
8. 列出需要客户明确的问题
9. 生成结构化评估报告
10. 构建评估数据结构，保存为 JSON 文件（参考 `example_history.json`）

### 后续评估流程（第2轮及以后）
1. 向用户确认项目名称
2. 读取并加载历史记录文件
3. 获取客户对上一轮评估的反馈
4. 查看历史记录，了解之前的评估情况
5. 根据反馈更新需求理解
6. 基于调整后的需求重新评估工作量
7. 生成更新后的评估报告
8. 更新历史记录数据结构
9. 保存更新后的历史记录到 JSON 文件

### 历史记录查看
1. 向用户确认项目名称
2. 读取历史记录文件
3. 显示所有轮次的评估记录和统计

## 评估标准

### 最小评估单位规则
- **最小评估单位为 1 人天**
- 单个功能点/任务评估小于 1 人天的，按 1 人天计算，或与其他相似小任务合并为 1 人天
- 多个小功能点可合并为一个功能组进行评估，每组最少 1 人天

### 模糊/不确定任务评估规则
- 对于需求描述模糊、技术方案不确定或边界不清晰的任务/模块，在基础评估工时上 **增加 40%**
- 计算公式：`最终工时 = 基础评估工时 × 1.4`
- 该类任务应在评估报告中单独标注，并列为需要客户澄清的优先问题

### 工作量评估参考
- **前端开发**：简单页面 1人天，中等复杂 1-3人天，复杂交互 3-5人天
- **UI设计**：简单页面 1人天，中等复杂 1-2人天，复杂 2-3人天
- **AI工程师**：简单集成 1-2人天，中等复杂 3-5人天，复杂系统 5-10人天
- **测试工程师**：简单 1人天，中等复杂 1-2人天，复杂 2-3人天，回归测试为开发工时 20-30%
- **PM项目经理**：项目规划 1-2人天，协调管理为总工作量 10-15%
- **部署运维**：环境配置 1人天，部署上线 1人天，总计为总开发工时 10-15%

### 隐含工时
- 沟通协调：总工时 5-10%
- 文档编写：总工时 5-10%
- 风险缓冲：总工时 10-15%
